03 · 唯一新 seam：durableWorkflow

为什么不能改 dsh 的 workflow

  • 它是 holder-owned、foreground、无 journal（上游 README 明示）。
  • 改它会破坏“最小语义”的设计目标。
  • 我们需要的 resume/留白/amend 是另一套持久化契约。

新 seam 的形状

  • ctx.durableWorkflow：start/resume/amend/cancel/get/list。
  • SQLite run store：runs / nodes / events / holes / questions。
  • 确定性 replay：node id = hash(script, path, args)。
  • 脚本在 worker + sandbox；只通过 facade 触达 Host。

05 · 不做什么

本版本明确不做

  • bots / 会话分享 / 手机远控 / 计费
  • MCP Apps（UI Plugin）——v2
  • Workspace 级插件 scope——用 profile/preset
  • 原地 rewind——用 fork
  • Android/iOS 模拟器、ZCode Sites

为什么

  • 它们是产品面，不是插件；工期远大于内核能力。
  • dsh 已覆盖 80% 的 UI/设置/MCP/技能基础。
  • 先把“ZCode 手感”落在工具、工作流、上下文上。
